The shell

Everything around your windows.

Nyx Shell sits on Hyprland: one live model of monitors, workspaces, notifications, and audio—drawn with your theme across the bar, dock, Control Center, Glimpse, and Task Switcher.

Nyx Dock

Pinned apps, badges, and rich context cards.

A floating bottom dock that steps out of the way when windows need space—with window previews, Unity badges, and right-click context cards.

  • Apps launcher grid opens with drag-to-pin ordering
  • Right-click cards surface active controls like Now Playing playback
  • Click cycles windows; middle-click spawns a new window

Build before switch

The Nyx System Manager builds each new generation in isolation first. Failed builds never touch the running desktop.

Generations & Limine boot

Every successful switch writes a clean Limine boot entry so rolling back is a single arrow-key press at startup.

NyxOS Recovery

Text-mode recovery console without compositor or network after administrator auth.

Btrfs snapshots

Snapper checkpoints wrap upgrades automatically for instant filesystem rollback.

Signed stable

stable and known-good channels only promote verified commits.

Install

Live USB. Encrypt by default.

Boot straight into the live Nyx desktop, partition cleanly or dual-boot beside Windows, and start with LUKS2 encryption enabled.

  • ISO Bootable live USB with full Wayland session
  • LUKS Disk encryption enabled by default
  • UEFI Aware of existing Windows EFI partitions
